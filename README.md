# 총판 ERP 분석 대시보드

ERP에서 내려받은 다음 세 파일을 업로드해 구조와 기본 지표를 확인하는 Streamlit 앱입니다.

- 매장 출고·반품 현황
- 상품 입고·반품 현황
- ERP 현재 재고 현황

현재 재고 파일은 날짜와 관계없이 ERP에서 방금 내려받은 최신 파일을 사용합니다. 제공된 2026년 1월 1일 파일은 컬럼 구조 확인용 샘플일 뿐, 기초재고 계산에는 사용하지 않습니다.

현재 버전은 상세 분석을 확정하기 전의 골격입니다. 소계·합계 행 제외, 거래 부호 표준화, 선택 월 범위의 전년 동기간 비교, 현재 재고와 기간 판매를 결합한 1차 구매판단까지 포함합니다.

## 실행

PowerShell에서 이 폴더로 이동한 후 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시된 `http://localhost:8501` 주소를 엽니다.

## GitHub와 Streamlit Community Cloud 배포

이 폴더는 GitHub 저장소 루트에 그대로 올릴 수 있도록 구성되어 있습니다.

- Streamlit 진입 파일: `app.py`
- Python 의존성: `requirements.txt`
- Streamlit 설정: `.streamlit/config.toml`
- ERP 엑셀 및 로컬 비밀 설정 제외: `.gitignore`

자세한 업로드 및 배포 순서는 `DEPLOY.md`를 확인하세요. 배포 시 Python 버전은 `3.12`를 선택합니다.

## 현재 정제 규칙

- 헤더가 1행 또는 2행에 있어도 ERP 컬럼명으로 자동 탐지합니다.
- 매출의 `창고`, 매입·재고의 `창고명`이 `총판`인 행만 분석에 포함합니다.
- 날짜로 해석되지 않는 소계·합계 행을 제외합니다.
- 매장 반품과 상품 반품은 음수, 출고와 입고는 양수로 표준화합니다.
- 현재 재고는 입출고로 추정하지 않고 업로드한 ERP 재고 수량을 직접 사용합니다.
- 아레나 9자리 품번은 두 번째 생산연도 자리를 제외하고 동일 상품군으로 묶습니다.
- 내부 상품군 키는 `브랜드 + 대분류 + 생산구분 + 핵심코드`입니다.
- 최종 발주판단 키는 `통합상품군 + 칼라 + 사이즈`입니다.
- 매출·매입 비교와 구매판단은 시작월과 종료월을 선택해 같은 범위로 조회합니다.
- 매출·매입 그래프의 축과 상세 수치는 천 단위 쉼표로 표시합니다.
- 발주 대상은 비교 분석연도와 무관하게 현재연도의 아레나 품번으로 생성합니다. 예: 2026년 `AC01` → `A6AC1AC01`.
- 발주 판단은 `월평균판매 = 기간 상품군 판매 ÷ 개월 수`, `목표재고 = 월평균판매 × 목표 보유개월`, `제안발주 = 목표재고 − 생산연도 통합 현재재고` 순서로 계산합니다.
- 발주 대상 품번의 거래처(매장)별 판매 합계와 월간 판매수량을 함께 확인할 수 있습니다.
- 발주표에는 각 컬러·사이즈에 연결된 실제 품번별 현재재고를 표시하고, 별도의 품번 × 컬러 × 사이즈 재고표도 제공합니다.
